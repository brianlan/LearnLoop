# LearnLoop

LearnLoop turns problems into practice material. Bulk ingestion lets a user review extracted problems before saving them.

## Language

**Bulk review**:
The part of bulk ingestion where a user checks and edits extracted problems before submission. In a variant batch, the user also reviews generated candidates.

**Source draft**:
The editable original problem extracted from an uploaded image. Generating a variant confirms the reviewed source draft.

**Variant candidate**:
A generated problem derived from a confirmed source draft. It must be reviewed and validated before it can become a practice problem.
